# Repository catalog

Research date: **2026-11-01**. **20 distinct public repositories verified and source-inspected: 17 deep, three focused.** All nine requested starting repositories exist and were inspected. The historical Auto-Maple fork is counted as a repository, not as independent corroboration. The Artale lineage also shares code; repository count is not algorithm diversity.

Deep = algorithm/control-flow source plus dependency/license inspection; focused = narrower relevant source inspection and metadata/license assessment. Neither means code was executed or gameplay validated. Latest commit means observed default-branch tip committer date, not push/update date; exact UTC times, SHAs, read-file inventories and license links are in the linked audits. Code-specific links below are immutable snapshots. Maintenance labels are observations at the audit date.

## Discovery beyond the catalog

Additional leads included `itechify/minerva`, `boggioMichael/ms`, the KenYu Artale upstream, `shaw-s-yu/realtime-game-vision`, and OC-SORT. They are **not counted as evaluated** and their implementation claims are not adopted. LinPolly and Jeremy already expose relevant Artale lineage; further fork reading had lower immediate value than generic tracking/capture inspection.

Searches also covered v62/v83/private-server and non-GitHub forges. Server-side/headless or memory-based bots were excluded because they do not answer the screenshot-only problem. Weakly relevant GitLab/Codeberg/Gitea results are documented in [open questions](open-questions.md), not added to meet a count. No executable, model or external test was run. No GitHub star count, author video or README benchmark was used as a reliability score.

## Licensing and maturity interpretation

Permissive licenses can allow adaptation with notices, but a root source license does not license bundled artwork, weights or every dependency. GPL-family projects remain useful algorithm references; actual reuse/distribution requires a deliberate compliance decision. No-license findings mean no permission was found, not an invitation to copy. All recommendations are ideas or proposed experiments, with no source transplant in this audit.

The generic trackers/capture libraries have substantial inspectable machinery, while Maple bots vary from small historical scripts to actively edited experiments. None was validated on this bot's exact Classic client/map/outfit. Source-supported findings are narrower and more useful than a blanket “working bot” label. See [comparison](computer-vision.md), [architecture](architecture.md) and [implementation priorities](improvement-backlog.md).
