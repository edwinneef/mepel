<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| runtime policy -> input queue | Logical actions cross from deterministic code into a real-world OS input subsystem. |
| input executor/watchdog -> Win32 SendInput | Concurrent threads can race safety state immediately before an irreversible external key event. |
| config.toml -> controller | Operator-editable key names and durations become physical input. |

## STRIDE Threat Register (ASVS L1; block on high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Spoofing | `KeyboardController` safety gate | high | mitigate | Recheck focus/calibration/obscuration, emergency state, stop generation, and enablement under the controller lock immediately before every key-down and lease renewal. |
| T-01-02 | Denial of Service | serial input queue and leases | high | mitigate | Use one bounded queue, bounded deadlines and total caps, terminal outcomes for cancellation, watchdog release independent of executor progress, and bounded thread joins. |
| T-01-03 | Tampering | `InputConfig`, `KEYS`, ordered chords | high | mitigate | Validate every configured key and finite bound at startup; encode chord ordering as tested constraints rather than caller-controlled event order. |
| T-01-SC | Tampering | npm/pip/cargo installs | high | mitigate | This plan adds no packages or package-manager install step; fail planning/execution if a third-party install is introduced without a Package Legitimacy Audit. |
</threat_model>
