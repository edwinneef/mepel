# Sketch Manifest

## Design Direction

Make the game preview compact and zoomable on the left. On the right, show actual game terrain with human-readable place names, an explanation of what was missing from the recording, and one clear next action. Keep internal IDs secondary. Inspect tracking failures before asking for another walk. Use the existing dark palette and actual teaching data.
